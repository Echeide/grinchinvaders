# Grinch Invaders - Revienta la Navidad 🎄💥

¡La terapia que no sabías que necesitabas! Destruye la Navidad y libera tu estrés en este divertido juego arcade estilo Space Invaders.

## 🎮 Sobre el Juego

**Grinch Invaders** es un juego de nave espacial donde controlas al Grinch (o su espíritu) para destruir regalos, adornos y todo lo que represente la alegría navideña.

### Características
- **Arcade Clásico**: Jugabilidad inspirada en Space Invaders.
- **Controles Móviles**: Optimizado para jugar en tu smartphone.
- **Giroscopio**: ¡Inclina tu dispositivo para moverte! (Opcional).
- **Power-ups**: Mejora tu disparo y velocidad.
- **Tabla de Puntuaciones**: Compite por ser el mayor Grinch.

## 🚀 Cómo Jugar

1. Accede al juego desde tu navegador.
2. Si estás en móvil, prueba usar el **Giroscopio** para una experiencia inmersiva.
3. Dispara a los regalos y evita que lleguen abajo.
4. ¡Acumula puntos y destruye la Navidad!

## 🛠️ Tecnologías

- HTML5 Canvas
- JavaScript (Vanilla)
- CSS3
